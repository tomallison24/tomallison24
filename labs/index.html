Two ways to set up

Try both on your iPhone, in Safari, then compare. Nothing here touches your real apps or settings.

Option 1 · aOS as one app

One Home Screen icon. Every app opens inside it, so you set up once.

  1. Open Test hub below, then Share, Add to Home Screen.
  2. Open it from the Home Screen and enter your name once.
  3. Tap Notes, then Weather: both already know you. Use the aOS pill to go back.
Open Test hub

Option 2 · separate apps, Face ID account

Each app has its own icon and its own (empty) storage. A passkey in your iCloud Keychain signs you in to each with one Face ID tap.

  1. Open Test A, Share, Add to Home Screen. Do the same for Test B.
  2. Open Test A from the Home Screen: Create my account (name, then Face ID).
  3. Open Test B from the Home Screen: Continue with Face ID. One tap, and it knows you.
Open Test A Open Test B

Try again with DuckDuckGo off

  1. Settings → General → AutoFill & Passwords: switch DuckDuckGo off for now; keep Passwords on.
  2. Open Test A, tap Sign out of this app, then Create my account again. Note what the save prompt says, and where it saves.
  3. Read the line under the buttons: does it say a findable passkey, on this phone?
  4. Check Settings → Passwords for tomallison24-news.pages.dev.
  5. Open Test B from its icon: Continue with Face ID.

If Test B only offers a QR code or security key

  1. Check Settings → General → AutoFill & Passwords: is anything besides Passwords (Apple's) switched on, like 1Password or Google? Apple has said another passkey manager can make the QR code appear.
  2. In Test B, tap the Tap for your passkey box instead of the button: does "Tom" show above the keyboard?
  3. Open Test B in a Safari tab (not the icon) and try again: does it find the passkey there?
  4. Check Settings → Passwords: is there a passkey for tomallison24-news.pages.dev?
  5. Screenshot the What this phone reports box at the bottom of Test B.
